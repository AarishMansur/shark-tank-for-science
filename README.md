# Shark Tank for Science

Entry for the NTP Novi Sad Hackathon, EINSTEIN track (Science-to-Business Matchmaker).

Every researcher and company pair has to survive a pitch room before a person ever sees it: scouts pitch pairs, two sharks grill them at the same time, a critic kills any claim it cannot trace to a record, and a writer turns the survivors into proposals.

Work in progress during the hackathon.
